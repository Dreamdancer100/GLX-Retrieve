## ✨ Features

- 🚀 **Undo closed tabs:** Brings back tabs you closed by accident.
- 🧩 **Instant shortcut:** One keyboard shortcut restores the last closed tab right away.
- ⚙️ **List of closed pages:** The toolbar pop-up shows recently closed pages with title and address.
- 🔒 **One click restore:** Pick any page from the list and it comes back.
- 📂 **Full tab session:** History of the tab is restored whenever possible.
- ⚡ **Scroll position:** The page opens where you left it.
- 🎨 **Fallback:** If the session is gone, the address is opened again.
- 🌍 **Adjustable memory:** Choose how many closed pages are remembered.
- 🛠️ **Your shortcut, your design:** Set the keyboard shortcut and the colour design.
- 📊 **Private:** No data leaves your browser.
